# Pneumonia Detection using Deep Learning

Capstone project for PGP in Artificial Intelligence and Machine Learning.

## Models Evaluated

- Baseline CNN
- Weighted CNN
- Weighted CNN with Early Stopping
- VGG16
- ResNet50
- Custom VGG16
- EfficientNetB0

## Final Selected Model

ResNet50
- Due to GitHub file size limitations, trained model artifacts are stored separately from the repository. The final selected model is ResNet50 (resnet50_final.keras).
